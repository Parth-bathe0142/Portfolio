{% endblock %} {% block logo %}{% endblock logo %} {# {% block logo_src %}/static/assets/images/cli-tools/logo.png{% endblock %} {% block logo_alt %}Simple CLI Tools logo{% endblock %} #} {% block accordion %} {% call macros::accordion_item("Bulk File Renamer", "bulk-renamer") %}

Renames every file in a folder by replacing part of the file name, or by adding a prefix or suffix. 

# replace text in file names
bfr -p "path/to/dir" --replace "old_text" --with "new_text"

# prepend text
bfr --start --with "prefix_"

# append text
bfr --end --with "_suffix"

# remove text (omit --with)
bfr --replace "text_to_remove"

--path defaults to the current directory. --replace, --start and --end are mutually exclusive; --start and --end both require --with. A --quiet flag suppresses the success log for each file.

{% endcall %} {% call macros::accordion_item("Wat Printer", "wat-printer") %}

A CLI wrapper around the wasmprinter crate that converts .wasm files to the human-readable .wat format, either one file at a time or in bulk across a directory. 

# convert a single file
wat-printer input.wasm [-o output.wat]

# convert every .wasm file in the current directory
wat-printer --all [-r]

--output defaults to the input file's name with a .wat extension. --all conflicts with passing a single input file, and can be combined with --recursive to walk subdirectories.
