VectorHue

Private Project -- WIP
{% endblock %} {% block summary %}

A web-based image vectorizer that converts raster images to SVG while recognising and preserving gradients, using a custom six-phase conversion pipeline. The output keeps the smoothness and detail of a raster image with the scalability and compactness of a vector.

Users upload an image, adjust a few conversion parameters, and download the result as SVG or compressed SVGZ. Most existing tools rely on simple edge detection and flatten gradients into solid colours. VectorHue instead runs a six-phase pipeline:

  1. Smoothing: a custom blur/sharpening filter that smooths gradients, removes anti-aliasing and noise, and refines edges.
  2. Identification: Gradients are identified using a modified flood fill algorithm that tolerates shifting colors. these regions are marked for further processing.
  3. Concave hull simplification: region borders are simplified by dropping points that don't contribute to the shape, which greatly reduces file size.
  4. Filtering duplicates: reusable gradients are identified and shared as definitions, reducing file size and improving editability.
  5. Writing the file: path elements and gradient definitions are written to the final SVG.

From TypeScript to Rust

The first prototype was the conversion process itself, written in TypeScript and running entirely in the browser. When performance issues started showing up, I rebuilt it in Rust as a server-rendered app using Axum and Askama, with HTMX and Alpine for interactivity.

Status

  • Heavily work in progress and not publicly available yet.
  • A Postgres database will be added once the core is working and ready to deploy.
  • Planned for later: smart layer separation, pattern filling and other advanced conversion features.
